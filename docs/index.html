                                    ประกอบหัวข้อ 4.1.1–4.1.2

                                    สรุปหัวข้อก่อนเขียนสมการ ให้นับตัวไม่รู้ค่าใน FBD เทียบกับจำนวนสมการสมดุล ซึ่งใน 2 มิติมี 3 สมการ ถ้าน้อยกว่า วัตถุเคลื่อนที่ได้ ถ้าเท่ากันและฐานรองรับจัดวางเหมาะสม หาแรงปฏิกิริยาได้ครบ ถ้ามากกว่า ต้องใช้ความรู้เรื่องการเสียรูปเพิ่ม ซึ่งไม่อยู่ในวิชานี้

                                    เลือกแกนให้ตัวไม่รู้ค่าหายไป

                                    ประกอบหัวข้อ 4.1.2 แนวทางการแก้ปัญหา (ค่าตรงกับตัวอย่าง 4.5: แรงร่วมจุด ไม่รู้ T กับ C)

                                    สรุปหัวข้อแกน x ไม่จำเป็นต้องเป็นแนวราบเสมอ ถ้าหมุนแกนให้ตั้งฉากกับแรงที่ไม่รู้ค่าตัวหนึ่ง แรงนั้นจะหายไปจากสมการของแกนนั้น เหลือตัวไม่รู้ค่าตัวเดียว แก้ได้ทันที คำตอบสุดท้ายเท่ากันไม่ว่าจะเลือกแกนแบบไหน

                                    เลือกจุดหมุนให้ตัวไม่รู้ค่าหายไป

                                    ประกอบหัวข้อ 4.1.2 (ค่าตรงกับตัวอย่าง 4.11: แท่งยาว 6 m หนัก 1177.2 N แขวนด้วยเชือก A และ B)

                                    สรุปหัวข้อแรงที่แนวแรงผ่านจุดหมุนไม่มีโมเมนต์รอบจุดนั้น ถ้าเลือกจุดหมุนที่มีแรงไม่รู้ค่าผ่าน สมการ ΣM จะเหลือตัวไม่รู้ค่าน้อยลง ลากจุดหมุน P ไปตามแท่งแล้วดูว่าสมการเปลี่ยนไปอย่างไร
                                    กดลูกศรซ้ายขวาบนแป้นพิมพ์เพื่อเลื่อนขั้นได้

                                    ลำดับที่ใช้ได้กับทุกโจทย์สมดุล(1) เขียน FBD (2) นับตัวไม่รู้ค่าเทียบกับจำนวนสมการ (3) เลือกจุดหมุนที่มีตัวไม่รู้ค่าผ่านมากที่สุด และเลือกแกนให้สะดวก (4) เขียนสมการทีละสมการ (5) แก้ แล้วตรวจด้วยสมการที่ยังไม่ได้ใช้

                                    คำถามชวนคิด

                                    วิธีใช้เลือกคำตอบในใจก่อน แล้วค่อยกด "เปิดเฉลย" คำถามเหล่านี้แทบไม่ต้องคำนวณ เน้นว่าเข้าใจแนวคิดหรือไม่ ถ้าตอบผิด อ่านคำอธิบายแล้วกลับไปลองในแท็บที่เกี่ยวข้องของบทนั้น

                                    แรงภายในชิ้นวัตถุ (คาน)

                                    ประกอบหัวข้อ 4.2.2 (แนวคิดตามรูปที่ 4.5: คานยาว 4 m รับแรง P กลางคาน ตัวเลขตั้งขึ้นสำหรับสาธิต)

                                    สรุปหัวข้อถ้าอยากรู้ว่าเนื้อวัสดุภายในคานรับแรงเท่าไร ให้ตัดคานที่จุดนั้นในจินตนาการ แล้วเขียน FBD ของส่วนใดส่วนหนึ่ง ที่หน้าตัดจะมีแรงภายใน 3 ตัว คือ แรงตามแนวแกน (Dx) แรงตั้งฉากแกน (Dy) และโมเมนต์ (CD) เพราะหน้าตัดยึดสองส่วนไว้แน่นเหมือนฐานยึดแน่น แรงบนสองส่วนมีขนาดเท่ากันทิศตรงข้าม (กฎข้อที่ 3 ของนิวตัน) จึงใช้ส่วนไหนคำนวณก็ได้ค่าเดียวกัน
                                    แรงปฏิกิริยา Ax = 5 kN, Ay = NB = 4.33 kN หาจาก FBD ของคานทั้งตัวก่อน (แบบบทที่ 4A) ส่วนคานจะรับแรงภายในเท่าไรนั้นใช้ในวิชากลศาสตร์วัสดุต่อ

                                    แยกชิ้นส่วน: แรงภายในที่จุดต่อ

                                    ประกอบหัวข้อ 4.2.1, 4.2.3 และ 4.3 (แนวคิดตามรูปที่ 4.6–4.7)

                                    สรุปหัวข้อเมื่อโครงสร้างประกอบจากหลายชิ้นต่อกันด้วยหมุด FBD ทั้งโครงอาจมีตัวไม่รู้ค่ามากกว่า 3 ตัว ให้แยกชิ้นแล้วเขียน FBD ทีละชิ้น ชิ้นละ 3 สมการ แรงที่จุดต่อระหว่างสองชิ้นเป็นไปตามกฎข้อที่ 3 ของนิวตัน คือขนาดเท่ากัน ทิศตรงข้าม

                                      หลักการสองแรงและสามแรง

                                      ประกอบหัวข้อ 4.4 (โครงในรูปที่ 4.10–4.14)

                                      สรุปหัวข้อหลักการสองแรง: วัตถุที่มีแรงกระทำแค่สองจุดและสมดุล แรงทั้งสองต้องขนาดเท่ากัน ทิศตรงข้าม และอยู่บนเส้นที่ลากผ่านสองจุดนั้น ทำให้รู้ทิศ เหลือตัวไม่รู้ค่าตัวเดียว หลักการสามแรง: วัตถุที่มีแรงสามแรงที่ไม่ขนานกันและสมดุล แนวแรงทั้งสามต้องตัดกันที่จุดเดียว ใช้หาทิศของแรงตัวที่สาม

                                        คำถามชวนคิด

                                        วิธีใช้เลือกคำตอบในใจก่อน แล้วค่อยกด "เปิดเฉลย" คำถามเหล่านี้แทบไม่ต้องคำนวณ เน้นว่าเข้าใจแนวคิดหรือไม่ ถ้าตอบผิด อ่านคำอธิบายแล้วกลับไปลองในแท็บที่เกี่ยวข้องของบทนั้น

                                        โครงถักและแรงในชิ้นส่วน

                                        ประกอบหัวข้อ 4.5.1 (รูปที่ 4.15) และรูปที่ 4.17

                                        สรุปหัวข้อโครงถักวิเคราะห์ภายใต้สมมติฐาน 3 ข้อ: ไม่คิดน้ำหนักชิ้นส่วน จุดต่อเป็นหมุด และแรงภายนอกกระทำที่จุดต่อ ชิ้นส่วนทุกชิ้นจึงรับแรงที่ปลายสองข้าง เป็นแรงตามแนวแกน ซึ่งเป็นแรงดึงหรือแรงอัด เวลาคำนวณให้สมมติเป็นแรงดึงไว้ก่อน ถ้าได้ค่าลบแปลว่าเป็นแรงอัด

                                          ระเบียบวิธีของจุดต่อ

                                          ประกอบหัวข้อ 4.5.2 (ตัวอย่าง 4.18 และโครงถักในรูปที่ 4.16–4.17)

                                          สรุปหัวข้อหาแรงปฏิกิริยาจาก FBD ของโครงถักทั้งชิ้นก่อน แล้วเขียน FBD ของหมุดทีละจุดต่อ แรงที่หมุดเป็นระบบแรงร่วมจุด จึงมีสมการ 2 สมการ (ΣFx, ΣFy) ให้เริ่มที่จุดต่อที่มีตัวไม่รู้ค่าไม่เกิน 2 ตัว แล้วไล่ไปจุดต่อถัดไป จุดต่อสุดท้ายใช้ตรวจคำตอบ

                                            ระเบียบวิธีของการตัด

                                            ประกอบหัวข้อ 4.5.3 (โครงถักในรูปที่ 4.18)

                                            สรุปหัวข้อตัดโครงถักผ่านชิ้นส่วนที่ต้องการ (ไม่เกิน 3 ชิ้นที่ไม่รู้ค่า) แล้วใช้ส่วนใดส่วนหนึ่งเป็น FBD ซึ่งเป็นวัตถุแข็งเกร็ง มี 3 สมการ เคล็ดคือเลือกจุดหมุนที่แนวของสองแรงที่ไม่รู้ค่าตัดกัน สมการโมเมนต์จะเหลือตัวไม่รู้ค่าตัวเดียว ไม่ต้องไล่ทีละจุดต่อ
                                            ลำดับงาน: (1) หาแรงปฏิกิริยาจาก FBD ทั้งโครงก่อน (2) ตัดผ่านชิ้นส่วนที่อยากรู้ ไม่เกิน 3 ชิ้น แล้วเลือกใช้ข้างที่มีแรงน้อยกว่า (3) วาดแรงในชิ้นส่วนที่ถูกตัดเป็นแรงดึง (ชี้ออกจากส่วนที่พิจารณา) (4) เลือกสมการที่ทำให้เหลือตัวไม่รู้ค่าตัวเดียว ลองกดสมการต่าง ๆ ด้านล่าง

                                            คำถามชวนคิด

                                            วิธีใช้เลือกคำตอบในใจก่อน แล้วค่อยกด "เปิดเฉลย" คำถามเหล่านี้แทบไม่ต้องคำนวณ เน้นว่าเข้าใจแนวคิดหรือไม่ ถ้าตอบผิด อ่านคำอธิบายแล้วกลับไปลองในแท็บที่เกี่ยวข้องของบทนั้น
                                            ลากบนภาพเพื่อหมุนมุมมอง

                                            ฐานรองรับใน 3 มิติ

                                            ประกอบหัวข้อ 5.2 (รูปที่ 5.1)

                                            สรุปหัวข้อหลักคิดเดียวกับ 2 มิติ: กันการเลื่อนทิศไหน มีแรงทิศนั้น กันการหมุนรอบแกนไหน มีโมเมนต์รอบแกนนั้น ต่างกันตรงที่ตอนนี้มี 3 ทิศและ 3 แกน ฐานรองรับจึงมีตัวไม่รู้ค่าได้ตั้งแต่ 1 ถึง 6 ตัว (ตัวเลขในวงเล็บ)
                                            ลากบนภาพเพื่อหมุนมุมมอง

                                            จำนวนสมการสมดุลอิสระ

                                            ประกอบหัวข้อ 5.1 และ 5.3 (รูปที่ 5.3)

                                            สรุปหัวข้อสมดุลใน 3 มิติคือ ΣF = 0 และ ΣMO = 0 เขียนเป็นสเกลาร์ได้ 6 สมการ แต่ถ้าระบบแรงมีลักษณะพิเศษ บางสมการจะเป็นจริงเองเสมอ (0 = 0) จึงใช้หาค่าไม่ได้ ก่อนแก้โจทย์ให้ดูว่าเป็นระบบแบบไหน แล้วนับว่ามีสมการกี่สมการเทียบกับตัวไม่รู้ค่า
                                            ลากบนภาพเพื่อหมุนมุมมอง

                                            แรงร่วมจุด 3 มิติ: เชือกสามเส้น

                                            ประกอบหัวข้อ 5.3.2 (ตัวอย่าง 5.4)

                                            สรุปหัวข้อเมื่อแรงทุกตัวผ่านจุดเดียว ใช้ ΣFx, ΣFy, ΣFz = 0 เขียนแรงตึงแต่ละเส้นเป็น Tλ ด้วยพิกัดสองจุด (บทที่ 1) แล้วแก้ 3 สมการ อีกทางคือใช้โมเมนต์รอบแกนที่เลือกให้แรงที่ไม่รู้ค่าสองตัวตัดแกน จะได้คำตอบทีละตัว
                                              ลากบนภาพเพื่อหมุนมุมมอง

                                              วัตถุแข็งเกร็ง 3 มิติ: ลูกบอลในเบ้ากับเชือกสองเส้น

                                              ประกอบหัวข้อ 5.3.4 (ตัวอย่าง 5.5)

                                              สรุปหัวข้อวัตถุแข็งเกร็งใน 3 มิติ ให้เลือกจุดหมุนที่แรงไม่รู้ค่าผ่านมากที่สุด (เช่น ข้อต่อลูกบอลซึ่งมี 3 ตัวไม่รู้ค่า) แล้วเขียน ΣMO = Σ(r × F) = 0 ซึ่งให้สมการ 3 แกนพร้อมกัน จากนั้นใช้ ΣF = 0 หาแรงที่จุดหมุน
                                                ลากบนภาพเพื่อหมุนมุมมอง

                                                แรงขนานใน 3 มิติ: แผ่นแขวนด้วยเชือกสามเส้น

                                                ประกอบหัวข้อ 5.3.3 (ตัวอย่าง 5.6)

                                                สรุปหัวข้อถ้าแรงทุกตัวขนานแกน z ใช้ได้แค่ ΣFz = 0, ΣMx = 0, ΣMy = 0 (3 สมการ) ลากจุดศูนย์ถ่วง G ไปบนแผ่นเพื่อดูว่าแรงตึงแต่ละเส้นเปลี่ยนอย่างไร และเมื่อ G ออกนอกสามเหลี่ยมของจุดผูกเชือก จะเกิดอะไรขึ้น

                                                วิธีใช้เลือกคำตอบในใจก่อน แล้วค่อยกด "เปิดเฉลย" คำถามเหล่านี้แทบไม่ต้องคำนวณ เน้นว่าเข้าใจแนวคิดหรือไม่ ถ้าตอบผิด อ่านคำอธิบายแล้วกลับไปลองในแท็บที่เกี่ยวข้องของบทนั้น

# Statics ทีละขั้น (statics-interactive)

สื่อเสริมแบบโต้ตอบ วิชาสถิตศาสตร์สำหรับวิศวกรรมเครื่องกล (50310264) ภาควิชาวิศวกรรมเครื่องกล คณะวิศวกรรมศาสตร์ มหาวิทยาลัยบูรพา
ใช้ประกอบเอกสารคำสอน "สถิตศาสตร์สำหรับวิศวกรรมเครื่องกล" ของ ผศ.ดร.อุทัย ประสพชิงชนะ ครอบคลุมบทที่ 1–5 (เนื้อหาก่อนสอบกลางภาค)

- เว็บสำหรับนิสิต: https://me-buu.github.io/statics-interactive/
- เอกสารทบทวนพื้นฐาน (PDF): https://me-buu.github.io/statics-interactive/review-handout.pdf

## โครงสร้าง

| ไฟล์ | เนื้อหา |
|---|---|
| `docs/index.html` | สื่อสำหรับนิสิต บทที่ 1–5 ทุกแท็บในไฟล์เดียว |
| `docs/review-handout.pdf` | เอกสารทบทวนพื้นฐาน (เวกเตอร์ ระบบสมการ ภาพฉาย) |

## การตั้งค่า GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` โฟลเดอร์ **`/docs`** → Save

## การอัปเดตรุ่นใหม่

อัปไฟล์ใหม่ทับชื่อเดิม (`docs/index.html`) เพื่อให้ลิงก์ของนิสิตไม่เปลี่ยน ประวัติรุ่นเก่าดูได้จากรายการ commit

## สิทธิ์การใช้งาน

ดูไฟล์ LICENSE หัวข้อ ตัวอย่าง และค่าตัวเลขอ้างอิงตามเอกสารคำสอนของ ผศ.ดร.อุทัย ประสพชิงชนะ รูปทั้งหมดวาดขึ้นใหม่สำหรับสื่อนี้
